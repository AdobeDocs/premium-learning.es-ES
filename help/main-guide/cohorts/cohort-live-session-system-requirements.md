# Requisitos del sistema para sesiones de cohorte en directo

## Prepárese para usar Adobe Connect

Las sesiones en directo se llevarán a cabo con Adobe Connect. Asegúrese de seguir estos puntos de comprobación para evitar problemas técnicos durante la sesión en directo:

1. Ejecute esta [prueba de diagnóstico](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm) para asegurarse de que Adobe Connect funciona correctamente en el sistema.
1. Revisa las [especificaciones técnicas](https://helpx.adobe.com/es/adobe-connect/connect-tech-spec/12-10-technical-specifications.html) para Adobe Connect.
1. Puede unirse a Adobe Connect a través de un explorador o de la aplicación de escritorio.
a) Si la aplicación de escritorio ya está instalada y tiene problemas, desinstale la aplicación de Adobe Connect y vuelva a instalarla con la última versión proporcionada [aquí](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html).

Encontrará el vínculo personalizado a la sala de reuniones virtuales en la invitación del calendario. El día de la formación, recomendamos lanzar el vínculo 5-10 minutos antes del inicio de la clase.

### Recursos adicionales

- [Centro de ayuda: Soporte técnico](/help/main-guide/technical-support.md)
- [Blog de soporte de Adobe Connect](https://blogs.connectusers.com/connectsupport/adobe-connect-best-practices/)

## Requisitos de hardware

- Ordenador o portátil con teclado y ratón
- 8 GB de RAM o más para un rendimiento óptimo del navegador.
- Se prefiere un segundo monitor externo
- Resolución mínima de 1280 x 768 píxeles
- Conexión a Internet de 100 Mbps o más

## Requisitos de software

- Los exploradores web recomendados son Chrome o Firefox
- Capacidad para acceder a la pantalla de inicio de sesión de [Adobe CX Enterprise](https://experience.adobe.com/) (consulte la nota siguiente)
- La información de inicio de sesión se proporcionará durante la formación
- Acceso a un editor de texto
- Un programa para extraer archivos de archivo (.zip)
- Un programa para leer archivos PDF, como [Adobe Reader](https://get.adobe.com/reader/)

>[!NOTE]
>
>No iniciar sesión. Simplemente pruebe que puede acceder al vínculo en su explorador sin que la red de su empresa lo bloquee. Puede ver el mensaje &quot;su Adobe ID no está vinculado a sus cuentas de solución de Adobe Experience Cloud&quot;, que se espera. El vínculo no está diseñado para que los alumnos accedan a nada antes de la clase. El primer día de clase, el instructor proporcionará las credenciales para iniciar sesión.
