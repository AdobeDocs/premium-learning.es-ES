# Requisitos adicionales del sistema por solución

## Desarrollo de Adobe Experience Manager Edge Delivery Services

Se requiere una cuenta personal y pública de GitHub.

## Adobe Experience Manager Sites

Los estudiantes tendrán acceso a la cuenta de la compañía Adobe Experience Manager de Premium Learning durante toda la clase para completar los laboratorios del curso.

Para los cursos técnicos de Adobe Experience Manager, use el software de máquina virtual **[!DNL ReadyTech]**. Antes de comenzar la clase, asegúrese de lo siguiente:

1. Completar [comprobación previa de rendimiento](https://adobe.instructorled.training/system-precheck)
1. Accesibilidad completa Comprueba previamente y verifica el acceso solo a la [[!DNL ReadyTech] pantalla de inicio de sesión](https://axis.readytech.com/#/login) (no inicies sesión).

## Adobe Campaign

El cliente de Campaign es una aplicación exclusiva de Windows. Si no tiene una máquina Windows para instalar el cliente de Campaign, se le proporcionará un entorno virtual denominado **[!DNL ReadyTech]** durante la clase.

Si no tiene una máquina con Windows o la capacidad de instalar software, asegúrese de lo siguiente:

1. Completar [comprobación previa de rendimiento](https://adobe.instructorled.training/system-precheck)
1. Accesibilidad completa Comprueba previamente y verifica el acceso solo a la [[!DNL ReadyTech] pantalla de inicio de sesión](https://axis.readytech.com/#/login) (no inicies sesión).

## Adobe Experience Platform

Algunos cursos técnicos de AEP usan **Postman** para actividades relacionadas con API. Si no puede realizar la instalación en el equipo, recibirá una máquina virtual llamada **[!DNL ReadyTech]** durante la clase.

Si no tiene la capacidad de instalar software, asegúrese de lo siguiente:

1. Completar [comprobación previa de rendimiento](https://adobe.instructorled.training/system-precheck)
1. Accesibilidad completa Comprueba previamente y verifica el acceso solo a la [[!DNL ReadyTech] pantalla de inicio de sesión](https://axis.readytech.com/#/login) (no inicies sesión).

## Adobe Target

Se recomienda descargar e instalar estas extensiones de Chrome:

* [Adobe Experience Platform Debugger](https://experienceleague.adobe.com/en/docs/experience-platform/debugger/home)
* [Compositor de experiencias visuales de Adobe Target](https://chromewebstore.google.com/detail/adobe-experience-cloud-vi/kgmjjkfjacffaebgpkpcllakjifppnca?pli=1)
